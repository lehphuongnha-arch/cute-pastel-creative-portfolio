# Cute Pastel Creative Portfolio

A responsive, self-contained portfolio website demo.

## Preview
Open `index.html` in a browser.

## Customize
- Search the HTML for `Sophie Le` to change the display name.
- Search for `hello@example.com` and replace it with your real email.
- Edit the About Me, skills, project names, descriptions, and SVG artwork inside `index.html`.
- The project category filters, project detail popups, mobile layout, theme toggle, and email-copy button are interactive.

## Publish online
Upload `index.html` to a static hosting service such as GitHub Pages, Netlify, or Vercel. This file is a working local website, but it is not automatically published to a public URL by this download.
